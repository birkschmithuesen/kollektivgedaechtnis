## THE SPEC CHANGE (Birk, 2026-08-14)

Spec §11 currently says node positions are persisted, existing nodes stay put, and the layout must never re-shuffle. That rule came from the Obsidian analysis (§4), where periodic reload re-rolled the force layout and nodes JUMPED. The enemy was JUMPING, not movement.

Birk now wants the opposite of static: when the graph changes — a new node arrives, or the density dial hides/reveals terms — ALL nodes should MIGRATE SLOWLY to a new, better-distributed arrangement, filling the freed space. Slow animated movement, never a re-roll from random. He explicitly wants this as the transition animation when a new node joins mid-view.

Additionally: node size and font size must adapt so the graph ALWAYS fills the screen without overcrowding. Two or three nodes → everything large. A hundred nodes → everything small. Never a fixed scale that eventually becomes unreadable.

Update spec §11 and §10.3 accordingly, and the plan. Keep the ANTI-JUMP requirement explicit: incremental, animated, never randomized.

## 🔴 USE THE LIBRARY, DO NOT HAND-BUILD THIS

Birk's explicit instruction: "Ich will nicht, dass wir das selber und händisch bauen, es gibt ja schon vorgefertigte Anzeige-Frameworks, die so was abbilden können." He is right, and I verified it against the cytoscape-fcose docs (github.com/iVis-at-Bilkent/cytoscape.js-fcose):

- `randomize: false` — incremental layout starting from CURRENT positions (requires `quality: "proof"`). This is the anti-jump guarantee, from the library.
- `animate: true` + `animationDuration` (+ `animationEasing`) — the slow migration, from the library.
- `nodeDimensionsIncludeLabels: true` — the layout accounts for label extents (valid in "proof" quality). This REPLACES our hand-rolled label-aware sizing.
- `fit: true` + `padding` — viewport fits the nodes after every run. Because Cytoscape font-size and node sizes are in model units, fitting automatically scales type and nodes with the zoom: few nodes → large, many nodes → small. This is the "always fills the screen" requirement, for free.
- `packComponents` via cytoscape-layout-utilities for disconnected components.
