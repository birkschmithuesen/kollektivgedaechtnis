# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities **privately** via GitHub:
[Report a vulnerability](https://github.com/birkschmithuesen/kollektivgedaechtnis/security/advisories/new),
or by mail to contact@birkschmithuesen.com. Do not open a public issue for security problems.

We are a small team and aim to answer within seven days.

## Before you send logs or screenshots

Remove API keys, tokens, passwords, hostnames and any personal content
(interview transcripts, names, recordings). Synthetic examples are enough to reproduce a problem.

## Supported versions

Only the current state of the default branch is maintained. Tagged versions mark past
productions and do not receive fixes.
