# ---------------------------------------------------------------------------
# 1. INFOMANIAK — Sprachmodell, Weckwort und Embeddings   [PFLICHT]
# ---------------------------------------------------------------------------
# Ein Schlüssel für drei Dinge. So steht es in der config.toml der Station:
#
#   llm_api_mode        = "chat_completions"
#   llm_model           = "moonshotai/Kimi-K2.6"
#   llm_url             = ".../ai/110416/openai/v1/chat/completions"
#   llm_reasoning_effort = "none"
#   wake_word_llm_model = "mistralai/Ministral-3-14B-Instruct-2512"
#   embedding_model     = "bge_multilingual_gemma2"
#   embedding_url       = ".../ai/110416/openai/v1/embeddings"
#
# Alle drei zeigen auf `api.infomaniak.com` (Schweiz), Konto SpekulationsRaum
# GbR, Produkt 110416.
#
# `llm_reasoning_effort = "none"` ist bei Kimi-K2.6 keine Feinheit, sondern die
# Bedingung, unter der das Modell überhaupt brauchbar ist (Messung 2026-08-31,
# echtes Extraktionsschema): ohne das Feld 0 von 5 gültigen Antworten, mit
# "none" 8 von 8 bei 1,3 s.

# 2. BLACK FOREST LABS — Bildgenerierung im Traum   [PFLICHT für den Traum]
# ---------------------------------------------------------------------------
# Deutscher Anbieter, EU-Endpunkt `api.eu.bfl.ai`.
BFL_API_KEY=

# 🔴 ACHTUNG — auf der Station war das am 2026-09-01 NICHT vollständig
# umgestellt: In ihrer `config.toml` stand KEINE einzige `image_`-Zeile,
# also galten die Vorgaben aus `kg2/config.py`:
#
#     image_api_mode = "openrouter"
#     image_model    = "google/gemini-3-pro-image"
#
# Das ist ein US-Weg (OpenRouter → Google), und der `BFL_API_KEY` lag ungenutzt
# daneben. Damit die Bilder wirklich über die EU laufen, müssen diese vier
# Zeilen in die `config.toml`:
#
#     image_api_mode    = "bfl"
#     image_url         = "https://api.eu.bfl.ai/v1"
#     image_model       = "flux-pro-1.1"
#     image_api_key_env = "BFL_API_KEY"
#
# NICHT "bfl_proxy" — das ist eine reine vServer-Eigenheit (dort hat uid birk
# per Firewall keinen Weg zu bfl.ai). Auf einem Ausstellungsrechner gibt es den
# Broker nicht, und der Traum rendert dann stumm nichts.

# ---------------------------------------------------------------------------
# NICHT GEBRAUCHT — und das ist der Punkt
# ---------------------------------------------------------------------------
# ANTHROPIC_API_KEY   und   OPENROUTER_API_KEY
#
# Beide stehen in `config.example.toml` als Vorgabe und in `scripts/start.sh`
# als Pflichtprüfung — die laufende Station setzt aber KEINEN von beiden. Sie
# sind der belegte Rückfallweg (der Referenzlauf 19c ist über Anthropic
# gefahren), im EU-Betrieb aber überflüssig.
#
# Wer sie setzt, hat einen Rückweg bei einem Infomaniak-Ausfall — und ein
# Datenschutzloch, sobald jemand die config umstellt, ohne es zu merken.
# Bewusst entscheiden, nicht vorsichtshalber eintragen.

# ---------------------------------------------------------------------------
# SPRACHERKENNUNG — läuft über Infomaniak, KEIN eigener Schlüssel nötig
# ---------------------------------------------------------------------------
# 🔴 An der laufenden Station abgelesen (Prozess-Kommandozeile, 2026-09-01):
#
#     python -m fundusapps.stt_server --language de infomaniak-whisper \
#            --channels regie --api-key-env HERMES_CUSTOM_API_INFOMANIAK_COM_API_KEY
#
# Also **Whisper bei Infomaniak** (Schweiz) — und der Dienst liest denselben
# Schlüssel wie oben unter Punkt 1. Deshalb steht hier keine eigene Variable:
# `HERMES_CUSTOM_API_INFOMANIAK_COM_API_KEY` trägt vier Dinge (Analyse,
# Weckwort, Embeddings, Spracherkennung).
#
# Der stt_server KANN auch rein lokal (`vosk`, `faster-whisper` mit
# large-v3-turbo auf dem Gerät) — das wird aber bewusst nicht genutzt, weil ein
# Ausstellungsrechner die Rechenlast nicht nebenher trägt. Die Wahl fällt beim
# START des Dienstes, nicht in dieser Datei.
#
# 🔴 Der Dienst liegt NICHT in diesem Repo (`stt_url = "http://127.0.0.1:5051"`
# spricht nur einen laufenden Prozess an). Auf dem Mac muss er also getrennt
# gestartet werden — auf dem Windows-Rechner tat das
# `kg-start\dienste\dienst-stt.bat`. **Für den Mac gibt es dafür noch keine
# Entsprechung; das ist ein offener Punkt vor dem ersten Interview.**
#
# LEHRE (für Agenten): Ich hatte hier zuerst "läuft lokal, verlässt den Rechner
# nicht" stehen — abgeleitet aus einer Kopie des stt_server in der RoboCloud,
# die von MAI stammt und den Infomaniak-Erkenner noch gar nicht enthielt. Eine
# alte Kopie ist kein Beleg für einen laufenden Dienst. Die Kommandozeile des
